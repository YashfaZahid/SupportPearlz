# Pearlz Home Systems — Refund & Returns Policy
**Version:** 2026.1  
**Last updated:** 2026-01-15

## 1. Return window

Customers may request a return within **14 calendar days** of the delivery date for eligible products purchased from the official Pearlz online store.

## 2. Condition requirements

| Condition | Eligible? | Notes |
|-----------|-----------|-------|
| Unopened, original packaging sealed | Yes | Full refund path if within window |
| Opened, unused, complete accessories | Yes | May incur restocking fee (see §6) |
| Used / installed / water contacted | No (return) | May qualify for warranty repair instead |
| Missing serial label or accessories | No | |

## 3. Who pays return shipping

- **Defective on arrival (DOA)** confirmed by Support: Pearlz pays return shipping.
- **Change of mind** within window, unopened: customer pays return shipping.
- **Change of mind**, opened: customer pays return shipping; restocking may apply.

## 4. Refund processing time by payment method

| Payment method | Typical processing after warehouse receipt |
|----------------|---------------------------------------------|
| Credit / debit card | 5–7 working days |
| Bank transfer | 7–10 working days |
| Store credit | 1–2 working days |

## 5. Non-refundable categories

- Opened filter cartridges and other consumables
- Installation fees already performed by Pearlz technicians
- Gift cards and promotional store credit
- Products damaged by misuse

## 6. Partial refunds and restocking

Opened but unused complete units returned within the window may receive a refund minus a **10% restocking fee**. Promotional bundles: if any item in the bundle is missing, refund is limited to the residual value of returned items at the promotional allocation, not the full bundle list price.

## 7. Return vs replacement vs warranty repair

- **Return:** product sent back for refund under this policy.
- **Replacement:** like-for-like unit when DOA is confirmed within 7 days of delivery.
- **Warranty repair:** defect after the return window; governed by the Warranty Policy and Service & Maintenance Agreement — not a refund.

## 8. Promotional bundles

Bundle pricing is non-separable for “price match” refunds. Returning one item from a bundle does not entitle the customer to the full bundle discount as cash.
