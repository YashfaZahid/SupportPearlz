# Pearlz Product Changelog / Firmware Release Notes
**Product:** AquaPearl 500 Pro connected module  
**Document version:** 2026.2

## Firmware 2.4 — 2025-11-12

- Changed the meaning of audible alert **E-04**: previously “generic filter due”; now specifically **carbon filter due** (aligned with Troubleshooting Guide).  
- Improved Wi-Fi reconnect backoff.  
- Fixed incorrect tank-full false positive on some serial batches.

## Firmware 2.3 — 2025-06-01

- Added in-app filter life estimates.  
- Baseline alert codes E-01 through E-08 as documented in the product manual.

## Firmware 2.2 — 2025-01-18

- Initial public connected-module release.

## Note on version conflict

If a customer’s unit is still on firmware **before 2.4**, verbal descriptions of E-04 may not match the current Troubleshooting Guide. Agents should ask the customer to check the firmware version in the app **Settings → About**.
