# Pearlz Troubleshooting Guide
**Version:** 2026.1  
**Products:** AquaPearl 300 / 500 Pro; AeroPearl Mini where noted

## How to use this guide

Match the symptom, try the customer-safe action, then escalate if the symptom remains. Symptoms marked **Do not self-repair** must be referred to Pearlz Support.

## Symptom table

| # | Symptom | Probable cause | Customer action | Escalate? |
|---|---------|----------------|-----------------|-----------|
| 1 | No power / blank display | Unplugged, dead socket, tripped switch | Check plug, try another socket, verify switch | If still dead |
| 2 | Low water flow | Clogged sediment pre-filter; kinked tubing | Replace sediment filter; straighten tubing | If flow still low after new filter |
| 3 | Leaking from base | Loose drain fitting; cracked fitting | Power off; tighten accessible fittings; mop water | **Yes — do not run wet electronics** |
| 4 | Bad / weird taste after install or filter change | Residual carbon fines; incomplete flush | Perform first-run flushing (see Installation Guide) | If taste persists after full flush cycle |
| 5 | Continuous running / never fills | Float sensor stuck; leak in tank sensor path | Power cycle; inspect for debris on float | If continuous after cycle |
| 6 | Three short beeps then stop | Error **E-03** — sediment pre-filter saturation | Replace sediment pre-filter; hold RESET 5 seconds | If beeps continue after reset |
| 7 | Blinking red LED | Error **E-05** — leak sensor wet | Power off; dry base sensor; find leak source | **Yes if LED returns** |
| 8 | TDS reading high | Exhausted RO membrane; bypass valve open | Check membrane age; close bypass | If TDS stays high with new membrane |
| 9 | Noisy pump | Air in line; dry run | Check inlet water; bleed air per manual | If noise is grinding metal |
| 10 | App will not pair | Bluetooth off; wrong model profile | Enable BT; reinstall app; factory reset Wi-Fi module | After two failed resets |
| 11 | One long beep repeating | Error **E-01** — no inlet water | Open inlet valve; check municipal supply | If supply confirmed |
| 12 | Two beeps repeating | Error **E-02** — tank full sensor fault | Power cycle; clean tank sensor contacts | If repeats |
| 13 | Four beeps | Error **E-04** — carbon filter due | Replace carbon cartridge; reset | — |
| 14 | Five beeps | Error **E-06** — pump overcurrent | Power off; check for blockage | **Do not self-repair pump** |
| 15 | Six beeps | Error **E-07** — UV lamp fault (500 Pro) | Contact support for lamp service | **Do not open UV bay** |
| 16 | Seven beeps | Error **E-08** — system fault | Power off; contact support | **Do not self-repair** |
| 17 | Warm purified water | Normal after long idle; or ambient heat | Draw 1 litre and discard; check placement | If water is hot |
| 18 | White residue in tank | Mineral scale | Descale per product manual schedule | — |

## Escalation criteria (must not attempt)

- Any smell of burning plastics or scorched electronics  
- Standing water inside the electronics bay  
- Cracked housing with active leak near mains power  
- UV bay access on AquaPearl 500 Pro  
- Pump replacement or control-board work
